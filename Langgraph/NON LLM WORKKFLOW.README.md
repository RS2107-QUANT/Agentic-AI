# Non-LLM workflow

Two deterministic nodes compute a rounded BMI from kilograms and metres and assign a sample category.

[Source file](NON%20LLM%20WORKKFLOW.ipynb) · [Setup](README.md)

## Run

Set `weight_kg` and a positive `height_m` in the invocation cell. No model or API key is needed.

## What to inspect

The graph prints `bmi` and `category`. The optional Mermaid PNG cell can require network access. This notebook is a graph exercise.
