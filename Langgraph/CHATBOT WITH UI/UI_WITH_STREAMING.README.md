# Streaming Streamlit chatbot

This interface displays model output as it arrives and supports multiple conversations in the current Streamlit session.

[Source file](UI_WITH_STREAMING.py) · [Setup](README.md)

## Run

Start Ollama with `llama3.2`, then run `python -m streamlit run UI_WITH_STREAMING.py` from the chatbot directory.

## What to inspect

Use **New Chat** to start a fresh thread. The sidebar lists threads added during the current session.
