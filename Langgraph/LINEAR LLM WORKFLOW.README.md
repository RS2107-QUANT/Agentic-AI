# Linear LLM workflow

A single OpenAI node reads a question from graph state and records the answer.

[Source file](LINEAR%20LLM%20WORKFLOW.ipynb) · [Setup](README.md)

## Run

Set `OPENAI_API_KEY`, edit `initial_state['question']`, and run the cells in order.

## What to inspect

The final cell prints the input question and the answer text in `final_state`.
