# Agentic AI — Learning & Implementations

This repository contains my hands-on implementations, practice code, and experiments as I explore **Generative AI and Agentic AI development**.

Most of the initial work follows the **CampusX Generative AI and Agentic AI courses**, where I've been learning how to build applications using Large Language Models, LangChain, and LangGraph.

The purpose of this repository is to document my learning, experiment with different concepts, and develop a deeper understanding of how AI agents and LLM-powered systems work in practice.

## What I'm Learning

- **LangChain:** Prompt templates, chains, output parsers, retrieval, and tool integration.
- **LangGraph:** State management, graph-based workflows, conditional routing, and agent orchestration.
- **Agentic AI:** Tool-calling agents, ReAct workflows, and multi-agent systems.
- **Retrieval-Augmented Generation (RAG):** Working with embeddings, vector stores, and external knowledge.
- **Ollama:** Experimenting with locally hosted language models.
- **Model Context Protocol (MCP):** Connecting AI applications with external tools and services.
- **Evaluation and Observability:** Understanding how to debug, evaluate, and improve agent performance.

## Tech Stack

**Language:** Python

**Frameworks:** LangChain, LangGraph

**Local Models:** Ollama

**Tools:** LangSmith, Jupyter Notebook, VS Code

Other libraries and tools will be added as I continue learning and experimenting.

## About This Repository

This is primarily a **learning and experimentation repository**, not a collection of production-ready applications.

The code includes implementations from tutorials, exercises, and my own experiments as I work toward building more advanced AI systems.

My main interests lie in **AI agent orchestration, tool use, multi-agent workflows, and developing practical AI applications**.
